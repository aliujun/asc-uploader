如何获取 API 密钥（.p8 文件）
  1. 登录 App Store Connect API 密钥页（用户和访问 → 集成 → App Store Connect API → 团队密钥）；
  2. 点击“生成 API 密钥”，需要 App Manager 及以上角色；
  3. 记下 Key ID 和页面顶部的 Issuer ID；
  4. 点击“下载”得到 AuthKey_XXXXXXXXXX.p8（只能下载一次，丢失需吊销重新生成）；
  5. 注意区分：.p12 分发证书用于签名（本工具“证书工具”页可生成）、App 专用密码是旧版 altool 用的，均不能用于此处。

第 1 步：生成私钥与 CSR

生成 RSA 2048 私钥（自动保存在本地）与证书签名请求（.csr）。

导入已有私钥（之前在别处生成的）

从 .p12 文件中提取私钥（蛋壳、Mac 钥匙串等导出的 p12）。提取的私钥与本地生成的统一管理， 可分别配合开发/发布 .cer 合成不同用途的 p12。

第 2 步：到 Apple 后台换取 .cer 证书

  1. 登录 Apple Developer - Certificates；
  2. 点击 + 新建证书，选择 Apple Distribution（或 iOS Distribution）；
  3. 上传第 1 步下载的 .csr 文件；
  4. 下载生成的 .cer 证书文件 回来。
